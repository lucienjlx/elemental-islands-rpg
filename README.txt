元素浮岛 V21.2 — GitHub 网页上传版

这一包来自已完成的 V21.2，只拆分文件，不改游戏玩法和模型。
包含 index.html、6 个 JS 文件和本说明；每个文件均小于 12 MiB。

发布步骤
1. 先解压 ZIP，打开解压后的文件夹。
2. 打开 https://github.com/lucienjlx/elemental-islands-rpg
3. 点击 Add file → Upload files。
4. 把 index.html 和全部 6 个 JS 文件一起拖进去。
   它们必须直接出现在仓库首页，与原有 README.md 同层。
   不要上传 ZIP，也不要套一层外部文件夹。
5. 等待所有文件上传完成，点击页面底部绿色 Commit changes。
6. 打开 Settings → Pages。
7. Source 选择 Deploy from a branch，Branch 选择 main，目录选择 /(root)，点 Save。
8. 等待发布完成，在 Pages 页面点击 Visit site。

预期网址（发布完成后才可访问）
https://lucienjlx.github.io/elemental-islands-rpg/

旧 HTML 的本地存档不会自动搬到网站，请先在旧游戏中导出存档，再在网站中导入。
